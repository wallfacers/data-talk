## 1. Color Tokens

### 1.1 CSS Variable Naming Convention

All dashboard stylesheets declare color tokens as CSS custom properties on `:root`. The
canonical variable names are:

| Token                        | Purpose                                      |
|------------------------------|----------------------------------------------|
| `--bezel-bg-app`             | Full-page body background                    |
| `--bezel-bg-panel`           | Semi-transparent panel / topbar / sidebar    |
| `--bezel-bg-card`            | Card surface (glass layer)                   |
| `--bezel-text-strong`        | High-emphasis text: titles, hero KPI values  |
| `--bezel-text-base`          | Primary body text                            |
| `--bezel-text-muted`         | Secondary / helper labels, axis text         |
| `--bezel-accent-primary`     | Brand accent: card-title bar, primary charts |
| `--bezel-accent-secondary`   | Supporting accent: gradients, secondary data |
| `--bezel-accent-warn`        | Warning state (amber/orange range)          |
| `--bezel-accent-success`     | Positive state (green range)                 |
| `--bezel-accent-danger`      | Alert / error state (red range)              |
| `--bezel-grid-line`          | Subtle chart grid line                       |
| `--bezel-grid-line-strong`   | Emphasized grid line or border               |

### 1.2 Default Neutral Values

When no industry override is specified, use this neutral dark palette:

```css
:root {
  --bezel-bg-app:           #0a0e1a;
  --bezel-bg-panel:         rgba(10, 18, 36, 0.60);
  --bezel-bg-card:          rgba(15, 23, 42, 0.55);
  --bezel-text-strong:      #e2e8f0;
  --bezel-text-base:        #cbd5e1;
  --bezel-text-muted:       #64748b;
  --bezel-accent-primary:   #00d4ff;
  --bezel-accent-secondary: #14b8a6;
  --bezel-accent-warn:      #f59e0b;
  --bezel-accent-success:   #10b981;
  --bezel-accent-danger:    #ef4444;
  --bezel-grid-line:        rgba(148, 163, 184, 0.08);
  --bezel-grid-line-strong: rgba(148, 163, 184, 0.20);
}
```

#### Accent-Derived Semantics

For each industry, derive state colors from the accent palette unless the industry
explicitly overrides:

| Token                    | Rule |
|--------------------------|------|
| `--bezel-accent-success` | Use `--bezel-accent-secondary` if it is a green tone; otherwise `#10b981` |
| `--bezel-accent-danger`  | Use `--bezel-accent-primary` if it is a red tone; otherwise `#ef4444` |
| `--bezel-accent-warn`    | Use `--bezel-accent-primary` if it is orange/amber; otherwise `#f59e0b` |

#### Card Surface Convention

For every industry, the `--bezel-bg-card` is constructed as:

```css
--bezel-bg-card: rgba(R, G, B, 0.55);
```

where `R, G, B` are derived by lightening `--bezel-bg-app` by approximately 30%. The
panel (`--bezel-bg-panel`) uses the same RGB at `0.60` opacity. Card borders use the
primary accent at low opacity:

```css
border: 1px solid rgba(var(--bezel-accent-primary-rgb), 0.18);
```

Each industry template should pre-compute and inline these values.

## 2. Typography

### 2.1 Font Stack

```css
font-family: 'PingFang SC', 'Microsoft YaHei', sans-serif;
```

Exception: **Cybersecurity** uses `'Courier New', Courier, monospace` for a terminal
aesthetic.

### 2.2 Type Scale

| Role          | Font Size    | Weight | Letter Spacing        | Additional                           |
|---------------|-------------|--------|-----------------------|--------------------------------------|
| Page Title    | 22 -- 28 px | 700    | 2 -- 8 px             | Gradient text or accent color        |
| KPI Numbers   | 24 -- 48 px | 700    | 1 -- 2 px             | `font-variant-numeric: tabular-nums` |
| KPI Labels    | 11 -- 12 px | 400    | 1 px                  | `color: var(--bezel-text-muted)`     |
| Card Title    | 13 -- 14 px | 700    | 1 -- 2 px             | Accent color; left bar via `::before`|
| Card Body     | 11 -- 12 px | 400    | 0                     | `color: var(--bezel-text-base)`      |
| Trend / Badge | 11 px       | 600    | 0                     | `font-variant-numeric: tabular-nums` |
| Clock         | 13 -- 15 px | 600    | 1 -- 2 px             | `font-variant-numeric: tabular-nums` |
| Subtitle      | 11 -- 12 px | 400    | 2 -- 4 px, uppercase  | `color: var(--bezel-text-muted)`     |
| Chart Axis    | 9 -- 11 px  | 400    | 0                     | `color: var(--bezel-text-muted)`     |

### 2.3 Card Title Bar Pattern

Every card title uses a colored left-bar accent via the `::before` pseudo-element:

```css
.card-title {
  font-size: 13px;
  font-weight: 700;
  color: var(--bezel-accent-primary);
  margin-bottom: 8px;
  display: flex;
  align-items: center;
  gap: 6px;
  letter-spacing: 1px;
}
.card-title::before {
  content: '';
  display: inline-block;
  width: 4px;
  height: 14px;
  background: var(--bezel-accent-primary);
  border-radius: 2px;
}
```

### 2.4 Tabular Numeric Alignment

All numeric displays (KPI values, trend percentages, counters, clocks) MUST use:

```css
font-variant-numeric: tabular-nums;
```

This ensures equal-width digit rendering so numbers do not shift during live updates.

## 3. Spacing

The spacing scale is a fixed set of values. Use multiples and combinations only from
this palette:

| Token Name   | Value  | Usage                                |
|-------------|--------|--------------------------------------|
| `--sp-1`    | 4 px   | Tight internal gap, icon-to-label    |
| `--sp-2`    | 8 px   | Card title margin-bottom             |
| `--sp-3`    | 12 px  | Dashboard grid gap, section padding  |
| `--sp-3.5`  | 14 px  | Card padding (horizontal), row gap   |
| `--sp-4`    | 16 px  | Column gap, section margin           |
| `--sp-6`    | 24 px  | Header padding, KPI row gap          |
| `--sp-8`    | 32 px  | Major section separation             |

### Common Layout Values

| Element        | Padding           | Gap               |
|---------------|-------------------|-------------------|
| Dashboard     | `12px -- 16px`    | `12px -- 16px`    |
| Card          | `12px 14px`       | internal: `8px`   |
| Topbar        | `0 24px`          | `16px` (KPI pill) |
| KPI Pill      | `0 18px`          | `2px -- 6px`      |
| Main Content  | `16px 16px 0`     | `14px -- 16px`    |

## 4. Radius

Two radius tokens cover all component shapes:

```css
:root {
  --bezel-radius-card: 12px;
  --bezel-radius-pill: 28px;
}
```

| Component       | Token                    | Value |
|----------------|--------------------------|-------|
| Card           | `--bezel-radius-card`    | 12 px |
| KPI Pill       | `--bezel-radius-pill`    | 28 px |
| Chart tooltip  | (inline)                 | 6 -- 8 px |
| Button / Badge | (inline)                 | 4 -- 6 px |
| Funnel bar     | (inline)                 | 8 px  |
| Inner elements | (inline)                 | 2 -- 4 px |

All corners use uniform radius (no per-corner variation).

## 5. Motion

### 5.1 Standard Transition

```css
transition: all 0.25s cubic-bezier(0.2, 0, 0, 1);
```

The easing curve `cubic-bezier(0.2, 0, 0, 1)` produces a fast-out / slow-in feel that
feels responsive but smooth. Apply this as the default for all interactive elements.

### 5.2 Duration Guide

| Element         | Duration | Easing                      |
|----------------|----------|-----------------------------|
| Card hover     | 300 ms   | `cubic-bezier(0.2, 0, 0, 1)` |
| Pill hover     | 250 ms   | `cubic-bezier(0.2, 0, 0, 1)` |
| Funnel bar     | 250 ms   | `cubic-bezier(0.2, 0, 0, 1)` |
| Border glow    | 250 ms   | `cubic-bezier(0.2, 0, 0, 1)` |
| KPI count-up   | 1500 ms  | `1 - (1-t)^3` (JS ease-out)  |
| Title breathe  | 3000 ms  | `ease-in-out` (infinite)     |
| Marquee scroll | 25 s     | `linear` (infinite)          |
| Slide-in       | 500 ms   | `ease-out`                   |

### 5.3 Hover Transforms

Cards and interactive elements use one of two hover transforms:

```css
/* Option A: Subtle scale */
.element:hover { transform: scale(1.02); }

/* Option B: Lift */
.element:hover { transform: translateY(-4px); }
```

Prefer `scale(1.02)` for cards and `translateY(-4px)` for funnel bars and standalone
interactive elements. KPI pills may use `scale(1.05)` for emphasis.

### 5.4 Hover Glow

On hover, add a border-color intensification and optional box-shadow:

```css
.card:hover {
  border-color: rgba(var(--accent-primary-rgb), 0.55);
  box-shadow: 0 0 18px rgba(var(--accent-primary-rgb), 0.15);
}
```

## 6. Background Effects

Each industry has a signature animated background layer. The effect is rendered on a
dedicated `<canvas>` or `<div>` element with `position: fixed; inset: 0; z-index: 0;
pointer-events: none;` so it sits behind all content.

### 6.1 Effect-to-Industry Mapping

| #  | Industry       | Effect            | Implementation Summary |
|----|----------------|-------------------|------------------------|
| 01 | Multi-Screen   | Starfield + Grid  | Canvas: 180 drifting star particles (white, random alpha 0.3--0.8). CSS grid overlay: `linear-gradient` lines at 40 px intervals, accent color at 3% opacity. |
| 02 | E-Commerce     | Particles         | Canvas: 80 upward-drifting particles in primary (red) and secondary (gold) colors, radius 0.5--2.5 px, alpha 0.1--0.6. |
| 03 | Manufacturing  | Scan Lines        | Pure CSS: `repeating-linear-gradient` on `body::before` with 2 px transparent / 2 px `rgba(0,0,0,0.08)` bands. `z-index: 9999; pointer-events: none`. |
| 04 | SaaS           | Gradient Blobs    | CSS: two large (55--60 vw) `border-radius: 50%` divs with `filter: blur(80px)` and radial gradients in primary/secondary colors. Floating animation over 12--15 s. |
| 05 | Finance        | Radial Glow       | CSS: `body::before` with `radial-gradient(ellipse at 50% 0%)` in secondary (blue) at 8% opacity. Width 80 vw, height 40 vh. |
| 06 | Logistics      | Grid              | Pure CSS: two-layer grid using `linear-gradient` at 20 px (6% opacity) and 80 px (3% opacity) intervals in primary (sky blue). |
| 07 | Healthcare     | Heartbeat Line    | SVG-based: animated `<path>` with `stroke-dasharray` / `stroke-dashoffset` cycling. Translates horizontally over 8 s. Color: primary (emerald). |
| 08 | HR             | Canvas Particles  | Canvas: soft floating particles, neutral warm tones. Subtle and unobtrusive. |
| 09 | Energy         | Waves             | SVG: multi-layer wave `<path>` shapes at bottom of viewport. CSS animation `translateX` + `translateY` over 8 s `ease-in-out infinite alternate`. Color: primary (green). |
| 10 | Cybersecurity  | Matrix Rain + Scan Lines | DOM-based: vertical columns of random characters scrolling downward via CSS animation. Additional `body::after` repeating gradient for scan lines in green. |
| 11 | Agriculture    | Sun Glow + Texture| CSS: large radial gradient ellipse at top-center simulating sunlight. SVG-based natural cross-hatch pattern as full-page texture at 6% opacity. |
| 12 | Education      | Glow + Texture    | CSS: top yellow radial glow via `body::before`. Subtle book-pattern texture via `body::after`. |

### 6.2 Implementation Pattern

All background effects follow this DOM structure:

```html
<!-- Background effect layer -->
<canvas id="bg-effect"></canvas>  <!-- or <div class="bg-wave">...</div> -->

<!-- Dashboard content -->
<div class="dashboard" style="position: relative; z-index: 1;">
  ...
</div>
```

The background element MUST have:
```css
position: fixed;
inset: 0;
z-index: 0;
pointer-events: none;
```

## 7. Glass Morphism

Every card and panel surface uses glass morphism. The three properties that define the
effect:

```css
.glass-surface {
  backdrop-filter: blur(12px);
  background: rgba(R, G, B, 0.55);
  border: 1px solid rgba(var(--accent-primary-rgb), 0.18);
}
```

### 7.1 Blur Range

| Element       | `backdrop-filter` |
|--------------|-------------------|
| Card         | `blur(12px)`      |
| KPI Pill     | `blur(8px)`       |
| Topbar       | `blur(12px)`      |
| Tooltip      | `blur(0)` (solid) |

### 7.2 Opacity Range

| Element       | Background Opacity |
|--------------|--------------------|
| Card         | 0.55               |
| Panel/Topbar | 0.60 -- 0.70       |
| Scene Card   | 0.50 -- 0.60       |
| Tooltip      | 0.92               |

### 7.3 Border Convention

Borders use the primary accent color at low opacity:

```css
border: 1px solid rgba(var(--accent-primary-rgb), 0.18);
```

On hover, the border intensifies:

```css
border: 1px solid rgba(var(--accent-primary-rgb), 0.55);
```

### 7.4 Card Top-Line Accent

Many industries add a subtle gradient line at the top of each card:

```css
.card::before {
  content: '';
  position: absolute;
  top: 0; left: 0; right: 0;
  height: 1px;
  background: linear-gradient(
    90deg,
    transparent,
    rgba(var(--accent-primary-rgb), 0.4),
    transparent
  );
}
```

## 8. ECharts Theme Baseline

All ECharts instances share a common dark theme. Each industry customizes the color
palette but inherits the structural configuration below.

### 8.1 Common ECharts Variables

These values are extracted from the template implementations and represent the standard
baseline:

```javascript
const bezelEChartsBase = {
  // Global
  backgroundColor: 'transparent',
  textStyle: {
    fontFamily: "'PingFang SC', 'Microsoft YaHei', sans-serif"
  },

  // Title
  title: {
    textStyle: {
      color: '#e2e8f0',
      fontSize: 14,
      fontWeight: 700
    }
  },

  // Legend
  legend: {
    textStyle: {
      color: '#94a3b8',
      fontSize: 11
    },
    top: 0,
    right: 8
  },

  // Tooltip (darkTooltip)
  tooltip: {
    backgroundColor: 'rgba(10, 18, 36, 0.92)',
    borderColor: 'rgba(0, 212, 255, 0.3)',
    textStyle: {
      color: '#e2e8f0',
      fontSize: 12
    },
    padding: [8, 12]
  },

  // Category Axis (darkAxis)
  categoryAxis: {
    axisLine: {
      lineStyle: { color: 'rgba(148, 163, 184, 0.20)' }
    },
    axisLabel: {
      color: '#64748b',
      fontSize: 10
    },
    axisTick: { show: false },
    splitLine: { show: false }
  },

  // Value Axis
  valueAxis: {
    axisLine: { show: false },
    axisLabel: {
      color: '#64748b',
      fontSize: 10
    },
    axisTick: { show: false },
    splitLine: {
      lineStyle: {
        type: 'dashed',
        color: 'rgba(148, 163, 184, 0.08)'

    }
  },

  // Grid (darkGrid)
  grid: {
    left: 48,
    right: 20,
    top: 32,
    bottom: 24,
    containLabel: false
  }
};
```

### 8.2 Grid Line Configuration (darkGrid)

The grid lines use a consistent subtle dashed pattern:

```javascript
const darkGrid = {
```

### 8.5 Gradient Bar Pattern

All bar charts use a vertical linear gradient from accent color (top) to transparent
(bottom):

```javascript
// For vertical bars
itemStyle: {
  borderRadius: [3, 3, 0, 0],
  color: new echarts.graphic.LinearGradient(0, 0, 0, 1, [
    { offset: 0, color: palette[0] },
    { offset: 1, color: 'rgba(palette-rgb, 0.15)' }
  ])
}

// For horizontal bars
itemStyle: {
  borderRadius: [0, 4, 4, 0],
  color: new echarts.graphic.LinearGradient(0, 0, 1, 0, [
    { offset: 0, color: palette[1] },
    { offset: 1, color: palette[0] }
  ])
}
```

### 8.6 Area Fill Pattern

All area / line charts use a gradient fill from semi-transparent accent to transparent:

```javascript
areaStyle: {
  color: new echarts.graphic.LinearGradient(0, 0, 0, 1, [
    { offset: 0, color: 'rgba(accent-rgb, 0.25)' },
    { offset: 1, color: 'rgba(accent-rgb, 0.02)' }
  ])
}
```

### 8.7 Heatmap / VisualMap Color Range

Heatmaps and map visual maps use a gradient range anchored at the industry's primary
accent:

```javascript
visualMap: {
  inRange: {
    color: [
      'rgba(bg-rgb, 1.0)',   // darkest (background tone)
      'rgba(mid-rgb, 1.0)',  // mid tone
      'rgba(primary-rgb, 1.0)',  // primary accent
      'rgba(secondary-rgb, 1.0)' // secondary accent
    ]
  }
}
```

Example for E-Commerce:
```javascript
inRange: {
  color: ['#1a0f0a', '#3e1a12', '#7a2e1e', '#b83e28', '#e05038', '#ff4444', '#ff6b35', '#ffc107']
}
```

### 8.8 Gauge Chart Configuration

Gauges follow a consistent structure:

```javascript
{
  type: 'gauge',

  endAngle: -20,
  min: 0,
  max: 100,
  splitNumber: 5,

    lineStyle: {

        [0.5, 'rgba(148, 163, 184, 0.1)'],  // low: dim

        [1, palette[0]]                        // high: primary
      ]
    }
  },
  pointer: {
    length: '55%',
    width: 3,
    itemStyle: { color: palette[0] }
  },
  axisTick: { show: false },
  splitLine: {
    length: 8,
    lineStyle: { color: '#64748b', width: 1 }
  },
  axisLabel: {
    distance: 12,
    color: '#64748b',
    fontSize: 9
  },
  detail: {
    valueAnimation: true,
    fontSize: 16,
    fontWeight: 'bold',
    color: palette[0],
    offsetCenter: [0, '70%'],
    formatter: '{value}%'
  }
}
```

### 8.10 Resizing

All ECharts instances MUST be registered for resize:

```javascript
const charts = [];
// ... after each echarts.init() and setOption() ...
charts.push(chartInstance);

window.addEventListener('resize', () => {
  charts.forEach(c => c.resize());
});
```
