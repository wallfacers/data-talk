# 08 HR — 人力资源分析中心

## 业务上下文
- **核心 KPI**: 总人数, 本月入职, 本月离职, 人均效能(万/人), 招聘完成率(%)
- **分析维度**: 人员结构(年龄/学历/职级 3 饼图), 组织架构力导向图, 人才九宫格(绩效x潜力), 离职趋势(12 个月), 招聘漏斗(简历->面试->Offer->入职), 员工满意度趋势, 薪酬带宽对标(boxplot), AI 离职风险预测热力图
- **典型用户**: HRD, HRBP, 招聘经理, 薪酬福利经理

## 视觉签名
- Primary color `#f97316` (orange) / Secondary color `#3b82f6` (blue) / Background `#1f2937`
- Network dot canvas background (80 animated dots with connecting lines)
- Card bg: `rgba(31,41,55,0.7)`, border: `rgba(75,85,99,0.5)`, blur backdrop
- Card title: 3px orange left border
- KPI cards: hover lifts with orange border glow
- Funnel bars: `linear-gradient(180deg, #3b82f6, #1d4ed8)`
- ECharts theme: transparent bg, `#e5e7eb` text, `#9ca3af` labels, `#374151` tooltip border

## 推荐布局骨架
- Header: ~40px — orange title + clock
- KPI row: 5 cards, ~70px
- Body: 3 columns 25% / 50% / 25%
- No bottom bar; all charts in columns

## 典型 widget pattern（6 个）

### hr.graph-force-org
- **When to use**: Organization structure as force-directed graph.
- **ECharts option fragment**:
```js
{
  series: [{
    type: 'graph', layout: 'force', roam: true, draggable: true,
    force: { repulsion: 380, edgeLength: [60, 140], gravity: 0.06 },
    data: depts.map((name, i) => ({
      id: String(i), name, value: size[i],
      symbolSize: Math.sqrt(size[i]) * 3.2,
      itemStyle: { color: riskColors[risk[i]] }
    })),
    links: links,
    emphasis: { focus: 'adjacency', lineStyle: { width: 2, color: '#f97316' } }
  }]
}
```
- **SQL output columns**: `dept_name TEXT, headcount INT, risk_level INT(0-2), source_dept TEXT, target_dept TEXT`
- **refresh.intervalMs**: 300000

### hr.mini-pie-structure
- **When to use**: 3 small donut charts for age/education/level distribution.
- **ECharts option fragment**:
```js
{
  title: { text: '年龄', left: 'center', top: 0, textStyle: { fontSize: 11 } },
  series: [{
    type: 'pie', radius: ['42%', '68%'], center: ['50%', '55%'],
    label: { show: true, fontSize: 10, formatter: '{b}\n{d}%' },
    data: [{ value: 520, name: '26-35岁', itemStyle: { color: '#f97316' } }, ...]
  }]
}
```
- **SQL output columns**: `dimension TEXT, segment TEXT, count INT`
- **refresh.intervalMs**: 300000

### hr.scatter-ninebox
- **When to use**: Talent 9-box grid (performance x potential scatter with zones).
- **ECharts option fragment**:
```js
{
  xAxis: { type: 'value', min: 0.5, max: 5.5, name: '绩效' },
  yAxis: { type: 'value', min: 0.5, max: 5.5, name: '潜力' },
  series: [{
    type: 'scatter',
    symbolSize: d => Math.sqrt(d[2]) * 5.5,
    data: [[perf, potential, count], ...],
    markArea: { silent: true, data: zoneRectangles },
    markLine: { data: [{ xAxis: 2.5 }, { xAxis: 4.5 }, { yAxis: 2.5 }, { yAxis: 4.5 }] }
  }]
}
```
- **SQL output columns**: `performance_score INT(1-5), potential_score INT(1-5), employee_count INT`
- **refresh.intervalMs**: 300000

### hr.line-area-turnover
- **When to use**: 12-month turnover trend with red area fill.
- **ECharts option fragment**:
```js
{
  series: [{
    type: 'line', smooth: true,
    lineStyle: { color: '#ef4444', width: 2 },
    areaStyle: { color: { type: 'linear', colorStops: [{ offset: 0, color: 'rgba(239,68,68,0.25)' }, { offset: 1, color: 'rgba(239,68,68,0.02)' }] } }
  }]
}
```
- **SQL output columns**: `month TEXT, turnover_count INT`
- **refresh.intervalMs**: 300000

### hr.boxplot-pay
- **When to use**: Salary bandwidth by level with market 50th percentile overlay.
- **ECharts option fragment**:
```js
{
  series: [
    { type: 'boxplot', data: levels.map((l, i) => ({ name: l, value: [min, q1, median, q3, max] })),
      itemStyle: { color: 'rgba(59,130,246,0.25)', borderColor: '#3b82f6' } },
    { type: 'line', data: marketP50, symbol: 'diamond', lineStyle: { color: '#f97316', type: 'dashed' } }
  ]
}
```
- **SQL output columns**: `level TEXT, min_salary NUMERIC, q1 NUMERIC, median NUMERIC, q3 NUMERIC, max_salary NUMERIC, market_p50 NUMERIC`
- **refresh.intervalMs**: 300000

### hr.heatmap-risk
- **When to use**: AI-predicted turnover risk heatmap (department x level).
- **ECharts option fragment**:
```js
{
  visualMap: { min: 0, max: 3, inRange: { color: ['#22c55e', '#f59e0b', '#f97316', '#ef4444'] } },
  series: [{
    type: 'heatmap',
    data: riskMatrix.flatMap((row, y) => row.map((v, x) => [x, y, v])),
    label: { show: true, formatter: p => ['低', '中', '高', '极高'][p.data[2]] }
  }]
}
```
- **SQL output columns**: `department TEXT, level TEXT, risk_level INT(0-3)`
- **refresh.intervalMs**: 300000
