## Why

`report-document-generation` 落地后，端到端验证暴露出 4 个影响用户感知的 ledger 报告生成缺陷：

1. **目录区域空白** — 报告 HTML/PDF 中 `<section class="ledger-toc">` 渲染出标题"目录"但内部 `<ol>` 为空，章节锚点也未生成。
2. **封面残留"DataTalk 自动生成"水印** — AI 在生成报告时把 cover 的 `author` 字段填成 "DataTalk 自动生成" 这类生成器自指文案，造成印刷品观感像广告横幅，违反 `design-language.md` 的视觉契约。
3. **HTML 预览字体回退到默认字体（BUG-0073，P1，open）** — Report Viewer iframe（`sandbox=allow-scripts srcdoc`）origin 为 `null`，加载 `_assets/fonts/*.otf` 被 CORS 拦截，思源宋体/黑体加载失败。PDF 不受影响（服务端 Chromium 直接读本地文件）。
4. **validator 单错误码 fail-fast** — `ReportSchemaValidator` 校验失败时只返回第一条违规，AI 必须多轮 retry 才能修齐所有问题；每轮带完整 `report.json`，token 浪费且容易陷入死循环。

四者根因独立但作用域全部落在 `report-document-rendering` 与 `report-data-contract` 两个 capability，合并在一个 change 里修复成本最低、回归一次到位。

## What Changes

- **TOC 渲染**：`ReportRenderer.renderToc` 实现章节锚点目录；`renderChapter` 给 `<section>` 加 `id="chap-{idx}"`；`MarkdownRenderer.renderToc` 同步输出 GFM 锚点链接。预扫描 sections[] 收集 chapter heading 并以 1-based index 编号。
- **Cover author 水印 sanitize**：
  - `ReportRenderer.renderCover` / `MarkdownRenderer` 渲染前对 `cover.author` 做 normalize：trim 后命中黑名单（`DataTalk*`、`AI 生成`、`自动生成`、`系统生成`、`Auto-generated`、`Generated by *` 等正则）则视为空，记 warn 日志。
  - `section-patterns.md` 与 `SKILL.md` 显式列出 author 字段禁用词清单 + "不确定就留空"的引导，从 prompt 端阻断根因。
  - 不动 validator —— 避免历史 promote 因升级出错。
- **`_assets/**` CORS 修复（关闭 BUG-0073）**：`ReportController.serveAsset` 响应头加 `Access-Control-Allow-Origin: *` + `Vary: Origin`。其他 API 端点保持现状，不开全局 CORS。
- **Validator collect-all 错误反馈**：
  - `ReportSchemaValidator.validate` 改为 collect 全部 violation 返回 `List<Violation>{code, path, message}`，不再抛出 `ReportValidationException`。
  - `PromoteReportActionHandler` 校验失败时返回 `{ error, errorCodes[], violations[], recoveryHints{} }` 结构，AI 一轮即可定位并修复全部问题。
  - `SKILL.md` 增加「promote 连续失败 2 次 → 停下汇总错误问用户」指引。
  - **BREAKING**（contract 内部）：`PromoteReportActionHandler` 错误返回结构由 `{error, errorCode}` 扩展为 `{error, errorCode, errorCodes[], violations[], recoveryHints{}}`。`errorCode` 保留兼容（取 `errorCodes[0]`），不会破坏已部署的 AI 提示。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `report-document-rendering`：新增 TOC 章节锚点目录的渲染要求；新增 cover author 水印 sanitize 行为；新增 `_assets/**` CORS 头要求。
- `report-data-contract`：validator 行为由 fail-fast 改为 collect-all；`PromoteReportActionHandler` 错误返回结构扩展；cover.author 字段语义增加禁用词约束。
