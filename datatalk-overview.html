Project Overview

DataTalk — AI 驱动的 智能数据库协作平台

Tauri 桌面应用 + Spring Boot 后端 + OpenCode AI 服务，三层架构，通过自然语言与数据库对话。

TL;DR

DataTalk 是一个桌面数据库协作工具。你在聊天框里用自然语言提问，后端通过 OpenCode 协议与 AI 服务通信， AI 生成 SQL 并执行，结果以表格、图表或 ER 图的形式呈现在前端。 支持 MySQL、PostgreSQL、H2 等数据库。技术栈：Tauri v2 + React 19 + Spring Boot 3.5 + Java 21。

系统架构

三层分离：桌面端 → 后端 → AI 服务，每层之间通过 HTTP（Streamable HTTP + SSE）通信。

后端分层架构

严格依赖方向：domain ← application ← infrastructure ← adapter（外层依赖内层，不可反向）。

01

Domain

领域模型：DtEvent sealed interface（22 种事件类型）、Part、Action、Ontology

02

应用服务：SessionBus、OpenCodeGateway、Action 注册与调度

03

基础设施：JDBC 实现、OpenCode HTTP 客户端、数据源连接管理

04

Adapter

适配层：REST 控制器、Spring 配置、应用启动入口

通信流程

用户在前端输入自然语言查询，整个请求链路如下：

用户在聊天框输入自然语言查询（如 "上个月销售额最高的 10 个产品"），前端通过 POST /api/session/{id}/chat 发送到后端。

OpenCodeGateway 将用户消息封装为 JSON-RPC 请求，通过 Streamable HTTP 发送到 OpenCode AI 服务。连接升级为 SSE，服务器持续推送事件。

  • message.part.created — AI 开始生成回复片段
  • message.part.delta — 流式文本增量
  • action.invoke — AI 请求执行 SQL（如 SELECT / EXPLAIN）

AI 生成 SQL 语句，通过 action.invoke 事件发送给后端。后端通过 ActionHandler 路由到对应的执行器，使用动态 JDBC 连接目标数据库执行 SQL。

执行结果通过 action_result 回传给 AI，AI 解读结果并生成自然语言回复。前端实时渲染流式文本、表格、图表和 ER 图。

  • 表格数据 → DataGrid 组件（排序、搜索、分页）
  • 图表 → Recharts 渲染（折线图、柱状图、饼图）
  • ER 图 → 自定义 SVG 渲染（表关系可视化）

前端执行完毕后，通过 POST /api/session/{id}/action_result 将结果回传给后端，后端再转发给 AI 服务，AI 据此继续生成回复或执行下一步操作。

关键设计约定

依赖方向

domain ← application ← infrastructure ← adapter，外层依赖内层，不可反向。

事件模型

DtEvent sealed interface，22 种事件类型，使用 exhaustive switch 保证编译时完整性。

Action 注册

创建 @DataTalkAction 注解的 ActionHandler Bean 即可自动注册，零核心代码改动。

前端状态管理

每个 feature 使用独立的 Zustand store，TanStack Query 管理服务端状态。useStageStore 是全局的、session 无关的——切换 session 不会改变 stage tabs 或 open/maximized 状态。

FAQ

Q: 支持哪些数据库？
MySQL、PostgreSQL、H2。通过动态 JDBC 连接，用户可以随时添加新的数据源连接。详见 docs/DATA_SOURCE_TYPE_COMPATIBILITY.md。
Q: 修改 domain 层后如何让后端生效？
使用 mvn install -pl <module> -am -DskipTests 而不是 mvn compile——因为 spring-boot:run 从 ~/.m2 加载非 adapter 模块的 jar 包。
Q: 如何添加新的 AI Action？
创建一个带有 @DataTalkAction 注解的 ActionHandler 实现类，Spring 会自动发现并注册它，无需修改核心代码。
Q: 前端的 stage 状态和 session 是什么关系？
useStageStore 是全局的、session 无关的。tabs、open、maximized、activeTabId 等是单一值，不是 per-session 的 map。切换活跃 session 不会改变 stage 的当前状态。
