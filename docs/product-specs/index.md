# 产品规格目录

产品功能定义和用户场景的集中索引。

## 产品定位

DataTalk 是面向数据工程师、分析师和开发者的智能数据库协作平台。核心价值：

- **交互革新**：聊天驱动，边说边查，边问边画
- **智能增强**：AI 理解数据意图、生成 SQL、推荐图表
- **可视协同**：内置 ER 图和报表能力
- **架构开放**：OpenCode 协议接入 AI，模型可替换

详细产品计划书见 [project_doc.md](../../project_doc.md)。

## 开发路线图

### 第一阶段：基础能力搭建 (MVP)

- 跑通核心流程：聊天中查询数据库
- 后端：连接管理、会话管理、OpenCode 集成、SQL 执行
- 前端：Tauri 骨架、主布局、连接管理 UI、聊天界面

### 第二阶段：核心功能深化

- 分栏交互（Manus 风格 HERO→SPLIT）
- 数据表格展示、ECharts 可视化、ER 图
- 支持 SQL Server、Oracle

### 第三阶段：智能化与体验优化

- 会话上下文持久化
- Agent 能力（数据洞察等）
- 用户认证、项目隔离
- 暗色/亮色主题
